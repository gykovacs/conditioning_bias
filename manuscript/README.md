# Manuscript

The paper behind this repository, kept here as an integral part of it. Previously this
lived in a separate repository (`gykovacs/paper_2023_conditioning_bias_springer`) that was
pulled into the workspace; these two versions are now self-contained and independent of it.

Each version directory holds everything it needs — its own `refs.bib`, class/style files,
figures and result tables — so it builds standalone and can be handed to a journal as a flat
submission package.

## Versions

### `original-submission/` — Springer, submitted 2024-03-23

The manuscript as originally submitted, extracted verbatim from commit `ea6786e` of the old
paper repository (the only state that was ever committed and pushed there). Uses the Springer
Nature `sn-jnl` class with the `sn-mathphys` reference style. 26 pages.

`submission-materials/` alongside it holds the cover letter, the contribution information
sheet, and the point-by-point response document that accompanied the submission.

Note that its `refs.bib` is the pre-revision bibliography, deliberately — it is the file as
submitted, not the later expanded one.

### `revised-elsevier/` — Elsevier reformat, 2025-08-25 (latest)

The current state of the paper. Uses the `elsarticle` class (`5p,twocolumn,authoryear`),
with the classification and regression result tables merged into combined tables and the two
score-distribution histograms dropped. 15 pages.

This is the endpoint of a revision that ran through five intermediate Springer-format drafts
(`paper_v2`–`paper_v6`) before being retargeted to Elsevier. Those drafts were never committed
anywhere and are not reproduced here; they remain in the original paper repository working
copy if they are ever needed.

## Building

Both versions build with the standard TeX Live toolchain, from inside their own directory:

```sh
cd original-submission && latexmk -pdf paper.tex
cd revised-elsevier   && latexmk -pdf paper_v6_elsevier.tex
```

`latexmk -C` cleans up afterwards. The checked-in `paper.pdf` / `paper_v6_elsevier.pdf` are
the reference outputs; a fresh build should reproduce them page for page.

## A caveat on the figures

`original-submission/` includes `hist-clas.eps` and `hist-reg.eps`, which are ~18 MB each.
They are **not tracked by git** — `*.eps` is ignored repository-wide, and these files were
deliberately purged from the history to keep the repository small.

This means a fresh clone will not build `original-submission/` until they are put back. They
are regenerated by [`study/006-distributions.ipynb`](../study/006-distributions.ipynb), which
writes them to `study/figures/`. Be aware that the copies in `study/figures/` were regenerated
during the revision and differ from the ones that went into the original submission, so
rebuilding from them will not reproduce the submitted PDF byte for byte.

`revised-elsevier/` is unaffected — it drops those two figures, and all of its figures are
small PDFs that are tracked normally.

## Where the numbers come from

The tables in both versions are generated from the study results, not written by hand:

- `original-submission/tab_*.tex` correspond to the files in [`study/tabs/`](../study/tabs/).
- `revised-elsevier/tab_*.tex` were produced by the scripts in
  [`study/revision/`](../study/revision/) — see that directory's README for which script
  generated which table, and in what order they were run.
